## array (list) :
Store multiple values in order, easy to access using index. Used in almost every problem for storing and iterating data.
```python
arr = [1, 2, 3]  # create
arr.append(4)    # add
arr[0]           # access first data
arr[1] = 10      # update
arr.remove(2)    # delete
len(arr)         # length
```
